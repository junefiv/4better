# 폰 프리뷰

Metro는 하나만 켠다. 이전 거 있으면 `Ctrl+C`.

`--localhost` 쓰지 말 것.

---

## 같은 Wi‑Fi

```powershell
npm run start:lan
```

Expo Go로 QR 찍거나, 그 터미널에서 `a`.

---

## 다른 망

```powershell
npm start
```

Expo Go로 QR 찍기.

---

## USB

터미널 A

```powershell
npm run start:usb
```

`Metro: exp://` 보이면 터미널 B

```powershell
npm run preview:usb
```

케이블 다시 꽂으면 터미널 B만 다시.

---

## 미리보기 로그인 (테스트)

로컬 더미가 아니라 **Supabase 계정**이다. 방 생성·타이머·체크가 서버에 남는다.

- 아이디: `git_in`
- 비밀번호: `123456789a`
- Auth email: `git_in@preview.4better.app`

로그인 화면에서 아이디·비밀번호를 넣고 **미리보기 계정으로 시작**을 누른다.

계정이 없으면 Supabase SQL Editor에서 `supabase/preview_login.sql`을 실행한다. Authentication → Providers에서 **Email**을 켜고, 테스트 동안 **Confirm email**은 끈다.

공유 테스트 비밀번호다. 정식 출시 전에 이 계정과 Email 비밀번호 로그인을 빼거나 비활성화한다.

```powershell
npm run preview:usb
```

# 4better 개발 현황

계획 원문은 [`개발_계획.md`](개발_계획.md)다. 이 문서는 **지금 어디인지**만 적는다. 구현이 스프린트를 닫을 때마다 이 파일을 고친다.

갱신: 2026년 9월 17일

---

## 한 줄

**V1 Core MVP 중반.** 화면은 V0를 지났고, 서버는 인증과 “혼자 방을 만들고 체크하는” 뼈대까지 붙었다. 계획의 핵심인 **2~4명이 초대·동의·제출·전원 확인·주간 확정**은 아직 닫히지 않았다.

> 혼자 방을 만들고 체크하는 뼈대는 서버에 붙기 시작했다.  
> “친구들과 확인하고 다음 주로 넘어가는가”는 아직 검증 전이다.

## 스프린트 체크리스트

완료는 서버에 붙어 **두 계정 이상으로 재현**될 때를 말한다. 화면만 있으면 미완이다.

| 스프린트 | 상태 | 있는 것 | 없는 것 |
|---|---|---|---|
| 0 정책·DB | 진행 | `schema.sql`, `v1_migration.sql`, `goal_presets.sql` | 예외 정책·API 목록을 개발 명세로 확정 |
| 1 인증 | 됨 | Google OAuth, 닉네임 설정, 세션 | 신고·차단. 탈퇴는 클라이언트 수준 |
| 2 방·초대 | 진행 | `create_league`, `fetchMyLeagues` | 초대코드/딥링크로 **다른 사람이** 참가, 전원 동의 후 시작 |
| 3 주차 엔진 | 진행 | 방 생성 시 week row | 주차 롤오버, `week_members` 스냅샷 확정 |
| 4 타이머·제출 | 진행 | `start/pause/finish_timer_session`, `submit_goal_check` | 서버 시각 복구 검증, 글/그림 **버전** 서버 저장 |
| 5 전원 승인 | 화면 | 승인·설명요청·미인정 UI | 본인 제외 전원 계산, 마지막 승인 시 확정 RPC |
| 6 결과·분배 | 화면 | 순위·예상 보상 화면 | 서버 산정, 동점, 1%·99% |
| 7 촬영·리캡 | 화면 | 카메라 진입, 날짜순 갤러리 UI | Storage 비공개 업로드, 승인된 미디어만 표시 |
| 8 연장·알림 | 화면 | 연장 동의 UI | 푸시 파이프, 미응답=비동의 서버 처리 |
| 9 베타 | 안 함 | Android Expo Go 프리뷰 | 실제 10방, 베타 지표 |

## 계획과 어긋난 점 (의도적으로 기록)

V1 계획은 **공부 타이머 + 글/그림 제출**만 베타 범위로 둔다. 앱 화면은 그보다 앞선다.

- 생성·홈 카드에 독서, 체크인, 러닝, 워킹, 자전거, 수면 등 프리셋이 이미 있다.
- 헬스와 장소 방문은 **체크인(`place`)** 으로 합쳤다. 레거시 `gym`은 migrate만 한다.
- 칩·그래프 색: 독서·공부 blue, 그림·글쓰기 orange, 자전거·러닝·워킹 lime, 체크인·수면 aqua.
- 홈 리그 카드 레이아웃·타이포는 최근 정리했다. 게이지 안 리캡 자리 표시 사진은 뺐다. 실제 리캡은 Sprint 7.

이 UI는 미리보기용이다. **센서·위치·걸음 구현으로 착각하지 않는다.**

## 코드에서 서버에 붙는 것

- 인증·프로필: `src/state/useAppModel.ts` (Google + 테스트용 `git_in` 미리보기 로그인)
- 원격 방·타이머·체크: `src/lib/remoteLeague.ts`  
  `create_league`, `submit_goal_check`, `start_timer_session`, `pause_timer_session`, `finish_timer_session`
- 승인(`reviewRecord`)은 아직 **로컬 배열만** 갱신한다.

## 지금 하지 않는 것

- GPS, 백그라운드 위치, Health Connect / HealthKit
- 게이지 안에 실제 리캡 미디어를 다시 넣는 일 (Sprint 7에서)
- 광고, 구독, 포인트
- 앱이 돈을 걷거나 보내는 기능

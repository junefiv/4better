# 목표 세션 체크 기준

리그 카드를 만들 때 고르는 목표와, 그 목표를 **읽었다 / 했다 / 갔다 / 일어났다**로 인정하는 방법.

숫자 `n`은 아직 기본값을 정하지 않은 설정이다. 구현 전에 이 문서에서 숫자를 확정한다.

---

## 1. 리그 카드 생성

한 카드는 목표 세션 **한 종류**만 고른다.

먼저 체크 주기를 고른다.

| 주기 | 의미 |
|---|---|
| 일 단위 | 하루마다 목표량을 채운다 |
| 주 단위 | 한 주마다 목표량을 채운다 |
| 월 단위 | 한 달마다 목표량을 채운다 |

그다음 세션을 고르고, 세션이 요구하는 측정 기준을 정한다. 주기별 목표량은 이 기준의 숫자다. 예: 주 단위 독서 2권, 일 단위 워킹 8,000걸음.

현재 세션:

| 세션 | 체크의 핵심 |
|---|---|
| 독서 | 독후감 텍스트 + 책을 들고 찍은 사진 |
| 글쓰기 | 텍스트. 손글씨형만 사진 |
| 그림 | 작품 사진 |
| 장소 방문 | 내가 찍은 위치에서만 체크 시작. 방문 여부 + 머문 시간 |
| 자전거 | 시작 버튼 후 거리·페이스·시간. 카드 목표는 거리 또는 시간 |
| 러닝 | 자전거와 동일 |
| 워킹 | 시작 버튼 후 거리·시간·걸음수. 카드 목표는 셋 중 하나 |
| 공부 | 순공 타이머. 앱을 벗어나면 멈춤. 1시간마다 화면 터치 |
| 아침형 인간 | 기상 알람을 끄고, n분 안에 걸어야 일어난 것으로 봄 |

빼는 것:

- **등산** — 삭제
- **헬스** — 장소 방문으로 대체. 헬스장에 가는 방은 장소 방문 카드로 만든다
- **수면시간** — 아침형 인간으로 변경

---

## 2. 공통

- 체크는 해당 세션 규칙이 충족됐을 때만 집계에 넣는다. 조건이 빠지면 제출되지 않거나, 제출돼도 카운트되지 않는다
- 시작 버튼이 있는 세션(장소 방문, 자전거, 러닝, 워킹, 공부)은 **버튼을 누른 뒤부터** 센다. 미리 한 활동은 소급하지 않는다
- 리캡 미디어(사진·영상)는 세션이 요구할 때만 필수다
- 실제 돈의 수납·송금은 없다

친구 확인(승인 / 설명 요청 / 미인정)은 업로드형(독서, 글쓰기, 그림)에서 허위 기록이 보일 때 쓴다. 위치·센서형(장소 방문, 자전거, 러닝, 워킹, 공부, 아침형 인간)은 앱이 조건을 만족했는지로 먼저 집계한다.

---

## 3. 세션별 체크

### 3.1 독서

읽을 책은 앱이 고르지 않는다. **리그 멤버끼리** 정한다. 주기마다 “몇 권”이 달라질 수 있어서다.

읽었다의 조건. 둘 다 있어야 한다.

1. 독후감 **텍스트**를 올린다
2. **책을 들고 찍은 사진**을 올린다

둘 중 하나라도 없으면 읽지 않은 것으로 본다. 책 표지만 바닥에 두고 찍은 사진, 빈 텍스트, 독후감 없이 사진만 있는 제출은 카운트하지 않는다.

한 권이 주기 목표의 1이다. 주 2권이면 조건이 갖춰진 제출이 두 번 필요하다.

### 3.2 글쓰기

텍스트 입력을 기준으로 쓴 것으로 본다. 리그 카드를 만들 때 글 종류를 하나 고른다.

| 종류 | 제출 | 쓴 것으로 보는 조건 |
|---|---|---|
| 블로그형 | 본문 텍스트 | 텍스트가 있어야 함 |
| 인스타형 | 짧은 본문 텍스트 | 텍스트가 있어야 함 |
| 시 | 시 텍스트 | 텍스트가 있어야 함 |
| 자유형 | 자유 텍스트 | 텍스트가 있어야 함 |
| 손글씨형 | 손글씨 **사진** | 사진이 있어야 함. 텍스트 칸만으로는 안 됨 |

손글씨형이 아니면 사진 없이 텍스트만으로 체크한다. 손글씨형은 사진이 없으면 카운트하지 않는다.

한 번의 유효 제출이 주기 목표의 1회다.

### 3.3 그림

사진으로만 인증한다. 그림이 보이는 사진이 있어야 그린 것으로 본다.

텍스트만, 빈 스케치북, 예전에 올린 것과 같은 사진으로 보이면 카운트하지 않거나 친구가 미인정할 수 있다.

한 장의 유효 작품 사진이 주기 목표의 1회다.

### 3.4 장소 방문

헬스장, 독서실, 카페처럼 **어디에 가기로 한 방**이다. 장소 종류는 멤버가 정하고, 앱은 위치와 체류로만 체크한다.

멤버마다 방문할 장소를 지도에서 **한 번 찍는다. 찍은 뒤 변경할 수 없다.**

체크 시작:

- 그 지점 반경 `n`미터 안에서만 **체크 시작**이 된다
- 그 지점이 아닌 곳에서 시작하면 카운트하지 않는다

진행 중:

- 반경 `n`미터를 벗어나면 체크를 **자동 종료**한다

집계:

- **방문 여부** — 유효한 시작이 있었는가
- **머문 시간** — 시작부터 반경 이탈 또는 직접 종료까지

주기 목표는 방문 횟수이거나 머문 시간이다. 카드를 만들 때 어느 쪽으로 셀지 정한다. (아직 기본을 횟수로 둘지 시간으로 둘지는 미정.)

### 3.5 자전거

시작할 때 **카운트 버튼**을 눌러야 한다. 누르기 전 이동은 넣지 않는다.

세션이 쌓는 값:

- 달린 **거리**
- **속도(페이스)**
- **시간**

리그 카드를 만들 때 목표 기준을 하나만 고른다.

- **거리로 체크** — 주기 목표를 km로 둔다
- **시간으로 체크** — 주기 목표를 분·시간으로 둔다

페이스는 기록에 남기되, 카드 목표의 달성 여부는 고른 기준만 본다.

### 3.6 러닝

자전거와 같다.

- 시작 버튼을 눌러야 카운트
- 거리, 페이스, 시간을 기록
- 카드 생성 때 **거리 또는 시간** 중 하나로 목표를 정함

### 3.7 워킹

시작할 때 **카운트 버튼**을 눌러야 한다.

세션이 쌓는 값:

- **거리**
- **시간**
- **걸음수(만보기)**

리그 카드를 만들 때 목표 기준을 하나만 고른다.

- 거리
- 시간
- 걸음수

만보기가 증가하지 않은 채로 **일정 시간**이 지나면 시간 카운트는 **자동으로 멈춘다.** 멈춰 있거나 폰만 켜 둔 채 시간을 쌓지 않기 위해서다. 걸음이 다시 늘면 재개할지, 다시 시작 버튼을 누르게 할지는 미정.

### 3.8 공부

순공 시간을 타이머로 센다. **세션 시작**을 누른 뒤부터다.

이 타이머만의 규칙:

- 다른 화면으로 이동하거나 앱을 내리면 **즉시 멈춘다.** 백그라운드에서 이어지지 않는다
- **1시간마다 화면을 터치**해야 한다. 터치가 없으면 그 이후는 세지 않는다. 잠든 채 타이머만 켜 두는 것을 막기 위해서다

타이머 화면 안에 **시험 타이머 UI**를 둔다. 일반적인 **수능 시계**와 같이, 남은 시간과 큰 숫자 시각을 한 화면에 둔다. 순공 카운트와 시험 시계는 같은 세션 화면 안에 있다.

주기 목표는 순공 시간이다.

### 3.9 아침형 인간

예전 수면시간 세션을 대체한다. 잔 시간이 아니라 **제시간에 일어났는지**를 본다.

리그 카드를 만들 때 **일어날 시간 알람**을 정한다. 멤버 공통 시각인지, 멤버마다 다른 시각인지는 미정. 초안은 카드에 정한 시각을 모두에게 쓴다.

체크:

1. 아침에 알람을 **끈다** — 여기까지는 아직 완전한 기상이 아니다
2. 알람을 끈 뒤 **`n`분 이내**에 핸드폰을 들고 **`n`걸음**을 걷는다 — 이때 **완전히 일어난 것**으로 본다

알람만 끄고 걸음이 없으면 **다시 잠듦**으로 체크한다. 주기 목표의 성공은 “완전히 일어난 날”만 센다.

## 4. 한눈에

| 세션 | 시작 방법 | 인정 조건 | 카드에서 고르는 목표 | 사진/글 |
|---|---|---|---|---|
| 독서 | 제출 | 독후감 텍스트 + 책 들고 찍은 사진 | 주기당 권수 | 글 필수, 책 든 사진 필수 |
| 글쓰기 | 제출 | 종류별 텍스트. 손글씨형은 사진 | 주기당 편수 | 손글씨형만 사진 필수 |
| 그림 | 제출 | 작품 사진 | 주기당 점 | 사진 필수 |
| 장소 방문 | 내 장소 반경 안에서 시작 | 시작이 유효하고, 벗어나면 종료 | 방문 횟수 또는 체류 시간 | 위치 고정, 이후 변경 불가 |
| 자전거 | 카운트 시작 | 이동 중 거리·페이스·시간 기록 | 거리 또는 시간 | 없음 |
| 러닝 | 카운트 시작 | 자전거와 동일 | 거리 또는 시간 | 없음 |
| 워킹 | 카운트 시작 | 거리·시간·걸음. 걸음 정체 시 시간 정지 | 거리 또는 시간 또는 걸음수 | 없음 |
| 공부 | 순공 타이머 시작 | 포그라운드 + 1시간마다 터치 | 순공 시간 | 없음. 수능 시계 UI |
| 아침형 인간 | 카드의 기상 알람 | 알람 종료 후 n분 안 n걸음 | 완전히 일어난 횟수 | 없음 |

## 5. 아직 숫자·규칙을 열어둠

구현 전에 여기 값을 채운다.

| 항목 | 초안 | 정해야 할 것 |
|---|---|---|
| 장소 방문 반경 | `n`미터 | 기본값. 카드마다 바꿀 수 있는지 |
| 장소 방문 목표 | 방문 횟수 또는 체류 시간 | 생성 화면에서 고르게 할지, 둘 다 보여줄지 |
| 워킹 걸음 정체 | 일정 시간 | 몇 초·분 뒤 시간을 멈출지. 재개는 자동인지 다시 시작인지 |
| 공부 터치 주기 | 1시간 | 확정. 터치 실패 시 그 시간 전체를 버릴지, 마지막 터치 이후만 버릴지 |
| 아침 알람 | 카드 생성 때 설정 | 전원 같은 시각인지, 멤버별인지 |
| 아침 걸음 | 끈 뒤 `n`분 안 `n`걸음 | 분과 걸음수 기본값 |
| 자전거·러닝 실내 | 미정 | 트레이너·트레드밀은 장소 방문으로 갈지, 이 세션에서 시간만 허용할지 |

---

## 6. 지금 구현과 다른 점

코드와 기획안은 아직 예전 전제를 따른다. 이 문서가 우선이다.

- 프리셋에 등산, 헬스, 수면이 남아 있다
- 일/주/월 주기 선택이 없다
- 독서·글쓰기·그림의 필수 조건이 세션별로 갈리지 않는다
- 장소 방문에 개인 고정 위치, 반경 이탈 종료가 없다
- 자전거·러닝·워킹에 거리·페이스·만보기가 없다
- 공부 타이머가 앱을 내려도 이어지고, 수능 시계가 없다
- 아침형 인간 알람·걸음 체크가 없다

---

## 7. 한 줄

주기는 일·주·월이다. 읽기·쓰기·그림은 올린 글과 사진으로, 장소와 움직임은 시작 버튼과 기기로, 아침은 알람을 끈 뒤 걸어야 체크된다.

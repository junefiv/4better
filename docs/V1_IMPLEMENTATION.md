## 제품 구조

홈의 우선순위는 `지금 할 일 → 이번 주 리그 → 확인 요청 → 주간 리캡`이다. 새 방 생성은 헤더와 플로팅 메뉴의 보조 액션으로 이동했다. 하단 고정 탭은 제거하고, Safe Area 안의 단일 플로팅 메뉴에서 홈·확인·리캡·설정으로 이동한다.

Shared Track은 주간 목표선을 기준으로 2~4명의 확정 실적 위치, 목표 통과, 확인 대기 값을 함께 표현한다. 순수한 백분율 바 대신 사회적 진행 상황을 읽는 것이 목적이다.

## 반응형

- 0~599px: 좌우 16~20px, 단일 컬럼
- 600~899px: 최대 680px 단일 컬럼
- 900px 이상: 최대 1040px, 리그 63% + 확인/리캡 35%

## 상태

로딩, 서버 오류, 오프라인, 리그 없음, 규칙 동의 전, 인원 대기, 진행 중, 타이머 수행, 제출 전 초안, 승인 대기, 설명 요청, 승인 확정, 목표 달성·미달성, 마지막 주, 종료, 리캡 없음, 카메라 권한 거절, 업로드 실패·재시도 상태를 컴포넌트 또는 QA 화면에서 처리한다.

## 아직 필요한 외부 설정

- Supabase publishable/anon key와 OAuth 공급자 콘솔 설정
- EAS projectId 및 APNs/FCM 자격 증명
- Supabase Storage의 private media 버킷과 서명 URL 정책
- Edge Function/작업 실행기에서 notification_jobs 처리
- 관리자 `is_admin` 권한의 안전한 서버 측 부여
- 실제 회원 탈퇴용 서버 함수와 법적 보존 정책 확정

# 타이포그래피

화면 글꼴은 **Wanted Sans**와 **Paperlogy**만 쓴다. 긴 문장·UI는 Wanted Sans, 제목·리그명·큰 숫자는 Paperlogy.

구현 전에 이 문서의 패밀리 이름과 용도를 그대로 맞춘다. 하나의 텍스트에 `fontFamily`와 `fontWeight`를 동시에 지정하지 않는다.

---

## 1. 파일 위치

TTF는 프로젝트 루트의 이 폴더에 넣는다.

```
assets/fonts/
```

로고(`assets/logo_4better.png`)와 같은 `assets` 아래다. 집에 가서 적용할 때는 `expo-font`로 이 경로의 파일을 로드하고, 아래 **등록 이름**을 `fontFamily`에 쓴다.

필요한 파일만 넣는다. Paperlogy 1Thin~6SemiBold, Wanted Sans Black / ExtraBlack / ExtraBold는 설치하지 않는다.

| 용도 | 실제 파일 | 등록 이름 |
|---|---|---|
| UI·본문 | `WantedSans-Regular.ttf` | `WantedSansRegular` |
| 강조 본문 | `WantedSans-Medium.ttf` | `WantedSansMedium` |
| 라벨·보조 숫자 | `WantedSans-SemiBold.ttf` | `WantedSansSemiBold` |
| 버튼(세미볼드 톤) | `WantedSans-SemiBold.ttf` | `WantedSansSemiBold` |
| 섹션·카드 제목·중간 숫자 | `Paperlogy-7Bold.ttf` | `Paperlogy7Bold` |
| 화면 제목·큰 기록 | `Paperlogy-8ExtraBold.ttf` | `Paperlogy8ExtraBold` |
| 핵심 숫자(`statXL`) | `Paperlogy-9Black.ttf` | `Paperlogy9Black` |

다운로드한 파일 이름이 다르면 폴더에 넣은 뒤, 로드 맵만 실제 파일명에 맞추면 된다. **등록 이름**은 바꾸지 않는 것이 좋다.

---

## 2. 패밀리

```ts
export const fontFamily = {
  wanted: {
    regular: 'WantedSansRegular',
    medium: 'WantedSansMedium',
    semiBold: 'WantedSansSemiBold',
    bold: 'WantedSansBold',
  },
  paperlogy: {
    bold: 'Paperlogy7Bold',
    extraBold: 'Paperlogy8ExtraBold',
    black: 'Paperlogy9Black',
  },
} as const;
```

---

## 3. 스케일

조금 컴팩트한 모바일 스케일이다. 캡션은 최소 12pt, 리그·카드 제목은 섹션 제목보다 한 단계 작은 `cardTitle`(17pt)로 위계를 나눈다. **단일 소스**는 `src/design/tokens.ts`의 `typography`다.

```ts
export const typography = {
  screenTitle: { fontSize: 26, lineHeight: 34 },
  sectionTitle: { fontSize: 20, lineHeight: 28 },
  cardTitle: { fontSize: 17, lineHeight: 24 },
  body: { fontSize: 15, lineHeight: 22 },
  bodyMedium: { fontSize: 15, lineHeight: 22 },
  bodySmall: { fontSize: 13, lineHeight: 19 },
  tab: { fontSize: 14, lineHeight: 20 },
  label: { fontSize: 13, lineHeight: 18 },
  chip: { fontSize: 12, lineHeight: 16 },
  caption: { fontSize: 12, lineHeight: 17 },
  button: { fontSize: 15, lineHeight: 20 },
  statXL: { fontSize: 40, lineHeight: 44 },
  statLG: { fontSize: 28, lineHeight: 34 },
  statMD: { fontSize: 20, lineHeight: 26 },
} as const;
```

(위 객체에는 `fontFamily`도 tokens와 동일하게 넣는다.)

화면·컴포넌트에서는 `typography.screenTitle`처럼 **토큰 이름**만 쓴다. `StyleSheet`의 **스타일 키**는 `body`, `label`, `caption`처럼 타이포 토큰과 같은 이름을 쓰지 않는다. Hermes에서 스타일 해석 시 `type` 관련 ReferenceError가 날 수 있다.

---

## 4. 사용 원칙

- **Paperlogy-9Black** → `statXL`(타이머·순위·핵심 숫자).
- **Paperlogy-8ExtraBold** → `screenTitle`, `statLG`.
- **Paperlogy-7Bold** → `sectionTitle`, `cardTitle`, `statMD`.
- **주요 탭**은 `tab`(14pt), **필드 라벨**은 `label`(13pt), **칩·배지**는 `chip`(12pt).
- 긴 문장과 설명은 모두 **Wanted Sans**를 쓴다.
- 하나의 텍스트에 `fontFamily`와 `fontWeight`를 같이 쓰지 않는다. 굵기는 파일(패밀리 이름)로만 고른다.
- 시스템 기본 폰트나 `fontWeight: '800'` 같은 숫자 굵기는  ent리 적용 후 제거한다.

## 5. 화면 적용 예시

| 텍스트 | 스케일 | 폰트 |
|---|---|---|
| WEEK 03 | `chip` | WantedSans SemiBold |
| 이번 주 리그 | `screenTitle` | Paperlogy 8ExtraBold |
| 독서 후 집중 클럽 | `cardTitle` | Paperlogy 7Bold |
| 주 10시간 · 4명 · 총 4주 | `caption` | WantedSans Regular |
| 현재 1위 | `label` | WantedSans Medium |
| 87% | `statXL` | Paperlogy 9Black |
| 8시간 42분 | `statLG` | Paperlogy 8ExtraBold |
| 목표까지 1시간 18분 | `bodyMedium` | WantedSans Medium |
| 소연님의 기록을 확인해 주세요 | `body` | WantedSans Regular |
| 확인 완료 | `button` | WantedSans SemiBold |

## 6. 코드 연결

- 폰트 로드: `src/design/useAppFonts.ts` · 앱 시작 시 `App.tsx`
- 토큰: `src/design/tokens.ts`의 `fontFamily`, `typography`
- Paper: `src/theme/paper.ts`
- 화면에서는 `typography.*`를 쓴다. 과거 `type.*` 별칭은 제거했다.

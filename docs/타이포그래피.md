# 타이포그래피

화면 글꼴은 **Wanted Sans**와 **Paperlogy**만 쓴다. 긴 문장·UI는 Wanted Sans, 제목·리그명·큰 숫자는 Paperlogy.

구현 전에 이 문서의 패밀리 이름과 용도를 그대로 맞춘다. 하나의 텍스트에 `fontFamily`와 `fontWeight`를 동시에 지정하지 않는다.

---

## 1. 파일 위치

TTF는 프로젝트 루트의 이 폴더에 넣는다.

```
assets/fonts/
```

로고(`assets/logo_4better.png`)와 같은 `assets` 아래다. 집에 가서 적용할 때는 `expo-font`로 이 경로의 파일을 로드하고, 아래 **등록 이름**을 `fontFamily`에 쓴다.

필요한 파일만 넣는다. Paperlogy 1Thin~6SemiBold, Wanted Sans Black / ExtraBlack / ExtraBold는 설치하지 않는다.

| 용도 | 실제 파일 | 등록 이름 |
|---|---|---|
| UI·본문 | `WantedSans-Regular.ttf` | `WantedSansRegular` |
| 강조 본문 | `WantedSans-Medium.ttf` | `WantedSansMedium` |
| 라벨·보조 숫자 | `WantedSans-SemiBold.ttf` | `WantedSansSemiBold` |
| 버튼·활성 탭 | `WantedSans-Bold.ttf` | `WantedSansBold` |
| 화면 제목 | `Paperlogy-7Bold.ttf` | `Paperlogy7Bold` |
| 리그명·카드 제목 | `Paperlogy-8ExtraBold.ttf` | `Paperlogy8ExtraBold` |
| 순위·기록·퍼센트 | `Paperlogy-9Black.ttf` | `Paperlogy9Black` |
| 작은 기록 숫자 | `Paperlogy-7Bold.ttf` | `Paperlogy7Bold` |

다운로드한 파일 이름이 다르면 폴더에 넣은 뒤, 로드 맵만 실제 파일명에 맞추면 된다. **등록 이름**은 바꾸지 않는 것이 좋다.

## 2. 패밀리

```ts
export const fontFamily = {
  wanted: {
    regular: 'WantedSansRegular',
    medium: 'WantedSansMedium',
    semiBold: 'WantedSansSemiBold',
    bold: 'WantedSansBold',
  },
  paperlogy: {
    bold: 'Paperlogy7Bold',
    extraBold: 'Paperlogy8ExtraBold',
    black: 'Paperlogy9Black',
  },
} as const;
```

현재 `src/design/tokens.ts`의 `type.display` / `title` / `heading` / `body` / `label` / `caption`은 이 스케일로 교체한다.

| 지금 토큰 | 바꿀 스케일 |
|---|---|

| `type.heading` | 리그명이면 `leagueTitle`, 영역 제목이면 `sectionTitle` |
| `type.body` | `body` 또는 `bodyMedium` |
| `type.label` | `label` 또는 버튼이면 `button` |
| `type.caption` | `caption` |

## 4. 사용 원칙

- **Paperlogy-9Black**은 큰 순위·퍼센트·결과 숫자에만 쓴다.
- **Paperlogy-8ExtraBold**는 리그명과 주요 기록에 쓴다.
- **Paperlogy-7Bold**는 화면 제목, 섹션 제목, 작은 기록 숫자에 쓴다.
- 긴 문장과 설명은 모두 **Wanted Sans**를 쓴다.
- 하나의 텍스트에 `fontFamily`와 `fontWeight`를 같이 쓰지 않는다. 굵기는 파일(패밀리 이름)로만 고른다.
- 시스템 기본 폰트나 `fontWeight: '800'` 같은 숫자 굵기는  ent리 적용 후 제거한다.

## 6. 집에 가서 할 일

1. 받은 TTF 7종을 `assets/fonts/`에 넣는다.
2. `expo-font`로 위 등록 이름에 연결한다. 폰트가 로드되기 전에는 화면을 그리지 않는다.
3. `src/design/tokens.ts`에 `fontFamily`와 `typography`를 이 문서대로 넣는다.
4. 화면의 `type.*`와 인라인 `fontWeight`를 스케일로 바꾼다.
5. 웹·Expo Go에서 제목/본문/버튼/큰 숫자가 서로 다른 얼굴로 보이는지 확인한다.
